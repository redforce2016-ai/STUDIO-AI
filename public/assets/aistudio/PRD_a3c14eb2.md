

# سند جامع مشخصات محصول: استودیو هوشمند تولید محتوا (Content Studio Desktop)

## ۱. چشم‌انداز و خلاصه محصول (Vision & Executive Summary)
- **نام نرم‌افزار:** Content Studio Desktop
- **نوع نرم‌افزار:** نرم‌افزار دسکتاپ ویندوزی برای اتوماسیون فرآیند ایده‌پردازی، پژوهش، نگارش سناریو، دکوپاژ و تولید شات‌های ویدیویی شبکه‌های اجتماعی (ریلز، شورتس، تیک‌تاک).
- **ارزش کلیدی:** حذف سردرگمی تولید محتوا با خط تولید هوشمند چندعاملی، در حالی که کنترل کیفی ۱۰۰٪ در دست کاربر باقی می‌ماند (Human-in-the-Loop).

## ۲. مخاطبان هدف (Target Audience)
- تولیدکنندگان محتوا و ادمین‌های شبکه‌های اجتماعی.
- کسب‌وکارهای آنلاین و آژانس‌های دیجیتال مارکتینگ.
- تیم‌های بازاریابی محتوایی نیازمند تولید مستمر ویدیوهای کوتاه عمودی.

## ۳. معماری خط لوله ۵ ایجنت محتوا (Content Production Line)
خط لوله نرم‌افزار از ۵ ایجنت متخصص داخلی تشکیل شده که خروجی هر یک، ورودی دیگری است:
1. **پژوهشگر (Researcher):** موضوع را دریافت کرده، در وب جستجو می‌کند، آمار، ترندها و زوایای جذاب را استخراج می‌کند.
2. **سناریونویس (Scriptwriter):** بر اساس نتایج پژوهش، سناریوی استاندارد بر پایه فرمول هوک (قلاب)، بدنه و کال‌تو‌اکشن (CTA) می‌نویسد.
3. **گوینده / نریشن (Voiceover):** متن سناریو را به لحن گفتاری مناسب تبدیل کرده و مکث‌ها و زمان‌بندی صوتی را تنظیم می‌کند.
4. **کارگردان / دکوپاژ (Director):** سناریو و زمان‌بندی را به شات‌های مجزا (Scene/Shot) می‌شکند و زوایای دوربین، استوری‌بورد و پرامپت تصویری هر شات را تدوین می‌کند.
5. **تولیدکننده بصری (Visual Asset Producer):** به ازای هر شات، تصاویر یا ویدیوهای زمینه و انیمیشن‌ها را تولید یا تجمیع می‌کند.

## ۴. الگوی تعاملی ترمز و تایید انسانی (Human-in-the-Loop Architecture)
نرم‌افزار به‌هیچ‌وجه به‌صورت یک‌باره و خودکار بدون اجازه کاربر خروجی نهایی تولید نمی‌کند:
- **ایستگاه تایید ۱:** کاربر سناریوی تولیدی را مطالعه، ویرایش یا تایید می‌کند.
- **ایستگاه تایید ۲:** کاربر لحن و متن نریشن را بازبینی می‌کند.
- **ایستگاه تایید ۳:** کاربر دکوپاژ و استوری‌بورد شات‌ها را بازبینی می‌کند.
- **ایستگاه تایید ۴:** کاربر خروجی‌های تصویری شات‌ها را به‌صورت مجزا ارزیابی، بازتولید یا نهایی می‌کند.

## ۵. پشته فناوری انتخاب‌شده (Tech Stack)
- **هسته پردازشی و پایپ‌لاین (Backend):** Python 3.11+, Pydantic v2, FastAPI/LangGraph Core, SQLite برای ذخیره آفلاین وضعیت پروژه‌ها.
- **رابط کاربری دسکتاپ (Frontend):** Tauri + React + TypeScript + Tailwind CSS (سبک، سریع و بومی ویندوز).
